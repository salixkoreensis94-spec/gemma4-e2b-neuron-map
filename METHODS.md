# Methods and scope of evidence

Model identity: base Gemma 4 E2B Q4_K_M, GGUF SHA256 `740185b21d22ceb83a11c3aa62ad5842ef32c70f6096d756bbee85a1e4ec34b8`. 35 layers, residual width 1536, vocabulary 262144. FFN widths are 6144 at L0–14 and 12288 at L15–34. Output embedding is tied. No weights are distributed. Round-1 data omit vocabulary IDs; round-3 data retain IDs for token-piece lookup.

## Static lens (S1b, replacing S1)

For write column v, compute `a = output_norm.weight * v / sqrt(mean(v²)+epsilon)`, `x=E a`, and population `z[t]=(x[t]-mean(x))/std(x)`. Group score is the mean z over its explicit whole-token allowlist, including exact leading-space-marker variants. All vocabulary IDs, including special/unused, enter mean/SD. The GGUF norm already contains the model's offset; do not add one again. Actual inference retains softcap `30*tanh(x/30)`; lens scoring/ranking uses pre-softcap x. Original post-softcap S1 register interpretations were withdrawn.

S1b face validity requires ≥10 of a group's top20 neurons to have ≥3 group-token IDs in their top20 tokens. Casual 0/20 and polite 4/20 fail. S6 uses the same lens statistic for four new frozen groups, with a full-vocabulary covariance identity and direct-logit spot checks. A lexical lens association alone is not a causal style effect.

Map columns casual/polite and S6 styles count full-group mean z >1.5, an explicitly exploratory S4 threshold. S1b retained only top/bottom50, group means and full-vocabulary moments. Address groups (explicit S4 multilingual informal-you and formal-you allowlists, including 너/你/ты/তুমি/तुम and 당신/您/usted/आप/আপনি respectively) were not original averaged groups. We therefore use the maximum observed address-token z and certify exhaustive counts only above the largest top50 boundary over all neurons: **z >21.5**, giving two informal and two formal neurons across all layers. Any omitted token is bounded by its neuron's last stored top50 logit. Observed address top-k lists are restricted to retained top50 evidence and are not certified global rankings. Small counts at this conservative threshold must not be read as no address association. Whole-token surfaces can be plural, homographic or used outside second-person address; this map does not resolve context. Exact lower-threshold full-group address maps cannot be recovered from these stored outputs; no new model computation was performed. Group membership strings and cutoff provenance are in `data/lens_map.json`.

## Contextual screen (S2 and S6)

Twelve fixed frames use six paired stems in casual/polite contexts. S2 statistic is `R=logsumexp(polite ending logits)-logsumexp(casual ending logits)`, shift `R(push)-R(None)`, averaged over frames. Screen last prompt position only, reusing exact unpushed prefix. Dose ±.5 qualifies; ±.8 is descriptive. Each layer has 512 original random directions. Original S2 criteria require strict control extrema, sign agreement ≥10/12 and Korean top1 proxy ≥11/12. The 39 narrower candidates additionally clear both-dose control extrema and expected-ending top1 in ≥11/12. S4 computes descriptive p05/p95 by linear interpolation at q*(N−1); these quantiles do not replace the original criteria. Signed ΔR, both tails and extrema are retained on cards.

S6 selects the top40 lens neurons per style, screens target-minus-partner ending groups at +.5, requires mean shift strictly above same-layer 512-control p95, then admits up to two per style. This yields eight admitted neurons; screen admission is not generation success. The S6 screen deliberately retains S2's validated cached numerical path; extraction/generation uses S3b ExactEngine(fma=True). A failed attempt to apply exact-generation operations to the cached screen was corrected before selection. The frozen rule's broad engine wording must be read with this implementation distinction.

## Push engine and numerical validation

`h_l += d * median_residual_norm_l * unit(v_l)` at l_out, after post-FFN RMSNorm, FFN and PLE residuals and layer output scaling. S3/S3b/S6 push all prompt/generated positions. Greedy argmax, lowest-ID ties, ≤96 new tokens, EOG excluded from reply length. Each condition resets state. Bundles use d/sqrt(k) per component; correlated components mean actual vector norms need not be equal. The reference register vector instead uses its raw L4–14 vectors × dose. Its dose is not comparable to residual-normalized neuron doses.

The custom GGUF engine dequantizes supplied weights and reproduces reference CPU activation rounding, quantized integer blocks, fp16 KV/attention, RoPE and libm compatibility tables. S2 versus stored llama.cpp CPU: top1 40/40, top10 mean overlap 9.45/10, max logit difference 2.15581131; S2's 12-frame unpushed top1 is 11/12. Generation validation S3/S3b/S6 matches original ten short CPU references 10/10 through EOG or cap; batched/single and zero-push comparisons also match. Four of the ten S3 references hit the cap. Reference prompts are 20–27 tokens whereas dev prompts are 81–90. Pushed complete generations and arbitrary longer contexts are not established CPU equivalent.

S2 all-position validation has high pooled correlation, but L14–34 equality is structural because of shared KV; early-layer evidence is only six neurons, Pearson .666 and sign agreement 76.39%. Do not generalize pooled correlations to early layers.

## Classifiers, proxies and pre-registration

S3/S3b split on sentence punctuation/newlines, inspect final Hangul words and count fixed suffixes. Unknown fragments stay in denominators. Dominance is strict >.5. A flip requires None source dominance and pushed target dominance. The S3b friend-largest condition uses a strict comparison with the other recognized ending families, plus flip; it requires seven replies, not 70% of fewer flips. Bounded second-person occurrences miss embedded malformed words, so a substring sensitivity count is also retained in source summaries.

S6 s6-endings-1.1.0 precedence: hasipsio, aegyo, haeyo, eumseum, haera, friend, other_casual. Unknown cannot win. Nominal homographs, quotations, malformed or truncated replies remain ambiguous. A build-only change removed 봄 from noun exclusions and added 림/짐/움 before the first validation evaluation. Validation is 126/128: friend 30/32, haeyo 32/32, four styles 16/16 each; other_casual unsupported. The two friend errors repeat one shared content template. Classifier validation pairs do not build directions or select conditions. Pure -다 does not identify social hierarchy; haera_core is a later descriptive count, never a qualification criterion.

Damage measures: Hangul fraction among Unicode letters; distinct character 4-gram fraction after whitespace collapse; generated-token length relative to matched None. Also track invalid bytes, replacements, truncation, repetition and cheap content-word overlap. None is unsteered but not a semantic gold answer. No damage proxy or overlap value is a human meaning-preservation score.

S3 bar: ≥8 flips/10; Hangul≥.95, D4≥.9, length ratio .5–2 each in ≥9/10; paired random ≤2 flips. S3b adds second-person delta≤.5 and friend+flip≥7/10 for casual targets. Polite-target flip ceiling is six due to None. S6 dev: dominance≥14/20; None/random≤3/20; each damage count≥18/20; pronoun delta≤.5. S6 selection is lexicographic by dominance, weakest quality count, lower dose, earlier layer and name. Full grid completed before no-knob reporting. Held-out twelve scenarios are descriptive, with no reselection or new pass rule. Prompt-only is one fixed line per style, not optimized prompting.

## Round 2: residual sensor measurement, selection and reading

**Model and fixtures.** Gemma 4 E2B Q4_K_M (base identity above), with four private per-character LoRA adapters A–D (alpha 32, rank 16, runtime scale 1); no adapters, package files, activations, residual dumps, token IDs or checkpoints are distributed. N0 was preparation with mixed historical label sources; its labels and human marks are not part of the N1b confirmatory evaluation or this round-2 data release. N0b generated 2,160 replies from 60 synthetic families × four characters × three arms × three decodes; 36/24 families were frozen dev/held-out. Arm a used LoRA plus ownership/identity notes where applicable; b removed those two notes; c used base plus a's notes. Common notes stayed fixed. Each prompt used greedy plus two full-vocabulary temperature-0.8 samples (fixed seeds 20261027/20261028), capped at 96 tokens including EOG. Four LoRA paths matched stored CPU greedy references 10/10 each during N0 preparation; N1b replay matched all 1,040 original arm-prompts through EOG/cap before capture. These are stored validation results, not inference rerun for this release.

**Labels.** Two independent AI judges (gpt-6.1-sol and gpt-6.1-terra), in separate blinded sessions, read complete synthetic context, canon and reply. Only exact primary agreement entered training/evaluation. R3 required agreement on none/mild/strong before collapsing mild/strong to positive. Disagreement was excluded, never relabeled negative; exact context/reply duplicates shared a judgment mapping. Raw-reply Cohen κ in N0b was R1 0.7203, R2 0.7379, R3 0.5160, R4 0.7758; N0c R1 κ was 0.7811. Unique-context/reply sensitivities were respectively 0.7044, 0.7263, 0.5049, 0.7702 and 0.7806. These measure AI agreement, not human-validated semantic accuracy.

**Held-out and freeze order.** N0b's R1 had only 26 held-out positives in four families, and its scripted context had grammar/particle defects. Before any probe evaluated N0b held-out R1, its entire R1 set was assigned to dev and a new N0c R1 held-out was planned. N0c froze 40 new families × four characters × a/b × three decodes (960 replies), with 20 quiz families and 20 ordinary-follow-up families and corrected scripted history; it was never expanded to chase positives. N0c raw labels were 57 positive / 874 negative / 29 disagreement; exact-duplicate sensor units retained 57 / 851. R3/R4 retained N0b's original splits. Families, all characters, arms and decodes stayed together in CV/bootstrap; broad motifs can recur across splits. N0b RULE preceded generation; N0c RULE preceded its generation; N0c labels froze before N1b RULE (2026-10-27 22:02:42 KST), followed by full replay, residual extraction, dev selection and one held-out evaluation. Held-out did not tune layers, thresholds or subtypes. R2 had descriptive counts only.

**Measured and selected.** Nine zero-based l_out layers {2,6,10,14,18,22,26,30,34} were read after attention/FFN/PLE residuals and output scaling. Reply features were mean and last content-token states, excluding EOG; pre-generation features were the last prompt token and mean over the last user's text tokens. Float32 accumulation preceded float16 storage. Primary captures used each character's LoRA; reading base-generated c replies under that LoRA is off-policy teacher forcing. Base residual results are auxiliary, not extra confirmatory passes. Reply units collapse exact character/full-context/reply duplicates; pre units are character×scenario×arm prompts with an agreed greedy target, with three-decode shares kept descriptive. The text baseline sees the reply, or only last-user text plus current Korean note lines before generation.

StandardScaler + L2 logistic regression selected layer, mean/last and C∈{.001,.01,.1,1,10,100} by grouped dev OOF AUROC (largest feasible 2–5 StratifiedGroupKFold; seed 20261027). Scaling and TF-IDF vocabularies fit training folds only. Word (1,2)-gram and character (2,5)-gram baselines used the same folds/C grid. Token-surprise candidates were mean, maximum and high-NLL 10% tail, using untempered logits from the capture model/adapter. Dev precision thresholds and the operating comparator were fixed before held-out. The frozen bars are in RESULTS.md and the rule copies. Twenty row and twenty equal-sized family-block label shuffles repeated the complete primary selection; they are selection controls, not held-out tests. Percentile 95% CIs used 2,000 family bootstrap draws; one-class draws were skipped and counted in JSON. The ≥40-positive rule counts sensor units, not independent families, so positive-family counts remain visible.

**Proxies and reading.** AUROC/precision/recall measure agreement with the selected AI labels. NLL is a surprise proxy. The owner probe uses agreed explicit true/surface-owner spans from correct replies and tests correct held-out generalization before reporting natural slips. Its majority/span-character/base comparisons and 28/23 separate constructed owner flips do not train the bad-reply detector. Their NLL shifts and readouts are reporting only, with no causal or fixability claim. Nonblind readings, including the optional input-note follow-up, do not revise frozen labels or decisions. The N0c note ledger was authored with the app's collision exclusion, not produced by its full reader; the follow-up restricted its main comparison to 46 scenarios whose off notes matched. All follow-up bars were frozen before generation and both arms were rejudged together; it does not establish live-app performance. Small positive-family counts, shared templates, moderate R3 agreement, distribution change and private adapters limit generalization. This release adds aggregates and protocol copies, not a runnable round-2 inference pipeline or a measured semantic-accuracy rate.

## Round 3 — measurement, proxy, selection and reading

**Measurement.** The fixed mix has 50M tokenizer-counted tokens, 53% Korean by source tag; 49,438,284 dev tokens in 263,910 independent ≤256-token chunks enter M1. A document-hash split holds out 561,716 targets. Exact document/token-chunk duplicates were removed. The input unit is GELU_tanh(gate)×up before ffn_down, across all 337,920 neurons; PLE, shared KV, post norms and layer scales remain in the model. The accepted map path is exact-dequantized FP32 reference d, with TF32/autocast off. The older custom CUDA rounding path failed the frozen numerical acceptance rule and was not used for the map.

Counts, signed mean/max, exact distinct-chunk top 20, language/script counts, histogram and a fixed 8,192-position reservoir were captured with cumulative commit/cursor checks. Quantiles are signed-log histogram midpoint estimates, not exact order statistics. The token top 10 is a reservoir positive-firing sample, not a full-stream token-frequency census. Published fixed rows retain exact integer counts and float32 maxima; means use float64, while quantile/lens values are serialized float32. The page shows 10 top and 10 bottom lens tokens, balancing a readable phone card and a bounded static footprint. Search covers the displayed positive-reservoir top 10, lens top 10, and every distinct token ID from the 20 strongest contexts, using the same normalized exact-piece matching. Strongest-context chips count token IDs over these 20 distinct-chunk maxima; ties sort by best context rank. They are descriptive evidence, not semantic labels. The list uses their first three, while the positive-reservoir sample remains in the closed card details. Maximum color edges are global 10/25/50/75/90/99th percentiles re-derived from all neuron maxima. Within-layer upper ranks include ties and use lazily loaded catalogs. A six-sentence bilingual guide and glossary explain tokens, layers, neurons, activation and lens limits.

**Proxy.** A static normalized write-column lens is not a causal token effect. Source language is not detected language. Template overlap and synthetic Gemma-generated Korean dialogue limit independence and generalization. Open-license snippets are observational examples; web rows have exact dataset/revision/file/row/token-offset pointers and no context text. Token surfaces matching privacy identifiers are withheld.

**Selection and pre-registration.** M2’s main sample is 40 neurons/layer, 6 std-scaled Gaussian directions/layer and 6 mixed donor items/layer. Its separate pilot is disjoint. All kinds use top 20 + 4 × 6 evidence, ±16 tokens, whole-chunk PII filtering, template cap 2 and the same fallback. Claude Opus 5.5, GPT gpt-6.1-sol (high), and Gemini 4 Argon High use the same prompt and category-majority rule; missing/invalid judges make an item unknown. Wilson p=b/(b+c), Newcombe direction comparison, mixed c≥.80 and κ follow the frozen design. Public snippets use a stricter ≤32-token window and the later boundary gate; they are not a reproduction of judge packets.

M3 trains skip TopK transcoders, width 16,384 and k = 32, on one dev pass at L5/L15/L27, and evaluates held-out FVU, loss, sparsity and fidelity. The original CE gate failed, then a disclosed post-hoc KL amendment replaced only fidelity, retaining score ≥ .80 / dead ≤ .10 and one scratch k = 64 retry. L15 failed the retry. L5/L27 judging is a further disclosed exploratory scope change; the fresh neuron comparison is not pooled with M2.

M4’s frozen population is 448 M2 c-neurons, 631 a-neurons and 280 b-neurons, with separate sets of 700 calibration and 210 validation pseudo-neuron pairs. It uses gradient×input over exact upstream residual components and one-position unit ablation/injection for downstream indirect log-probability effects, with actual final norm. Spectral bipartitions have both groups ≥ 3 and minimize normalized cut. Band-specific calibration 95th-percentile thresholds define shared shares; rho=(f_c−f_0)/(f_a−f_0), 10,000 stratified bootstrap draws and 97.5% intervals account for two sides. V1/V2 numerical, V3 floor/exclusion and V4 sensitivity gates fail closed.

**Reading.** M2 rejects the registered H under valid controls. M3 feature interpretability findings are exploratory. M4 has no scientific verdict because its gates fail. Test–retest, panel differences, template dependence and sparse-space random controls remain visible limitations. A separate post-hoc paragraph discusses the floor; the gate failure remains the pre-registered outcome. Sanitized protocol copies preserve thresholds/procedures; their source hashes identify originals and their copy hashes verify the distributed redactions.

No rehydration tool is included: exact reconstruction would need the GGUF tokenizer and the fixed 2.15 GB FineWeb-Edu file to prove matching chunk hashes; exact source pointers are supplied instead.

Main-script summaries count all positive token positions, independently of the strongest-context token counts. M5h changes display marks and the data-only starting examples; it leaves activations, snippet bytes, filters and search normalization unchanged.
