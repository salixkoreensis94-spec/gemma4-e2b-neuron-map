# Gemma 4 E2B 뉴런 지도

**작성자: Ryou Jiho**

Copyright 2026 Ryou Jiho.

질문은 뉴런 하나의 쓰기 방향이나 작은 대비 방향을 더해서, 답변의 내용을 지키며 한국어 말투를 바꿀 수 있는가다. @_lyraaaa_의 neuron-explorer 아이디어를 참고했으며 그 코드는 사용하지 않았다. 한 기본 Gemma 4 E2B Q4_K_M GGUF를 쓰며 LoRA는 없다.

[잰 값] 35층·337,920뉴런의 W_down 열을 최종 RMSNorm과 묶인 출력 임베딩으로 읽었다. 렌즈는 포화 전 로짓이다. 이어 12개 문맥의 다음 토큰 어미 점수 변화와 짧은 고정 대화 생성을 쟀다. 생성 때는 층의 잔차 노름 중앙값 × 용량 × 단위 방향을 FFN·PLE 잔차와 층 출력 배율 뒤 l_out에 더했다. 실제 뉴런 활성이나 가중치를 직접 고친 것은 아니다.

| 단계 | 고정 기준의 결과 |
|---|---|
| S1b | 반말·존댓말 얼굴 타당성 0/20·4/20, 둘 다 실패 |
| S2 | 원래 선별 582개, 두 부호 대조 극값 검사 366개, 엄격 어미 조건까지 39개 |
| S3 | 엄격 39개는 모두 미통과. 별도 L27 N1939는 +0.5·+0.8에서 각각 9/10 전환으로 자동 통과 |
| S3b | 더 엄격한 친구 반말 기준은 전부 미통과 |
| S6 | 하십시오체 L27 +0.65만 dev 자동 통과: 목표 우세 18/20, held-out 11/12 |

[읽기] 자동 통과는 뜻 보존의 증거가 아니다. 원문에는 조어·주체 변경·사실 오류가 남는다. 한글·문자 4그램·길이 기준은 이를 놓쳤다. 고정 prompt-only 한 줄은 dev에서 하십시오체 20/20, 해라체 17/20이었고, 선택 손잡이는 하십시오체 18/20, 해라체 최상 미통과는 13/20이었다. 이 조건의 말투 변화는 보이지만 신뢰할 수 있는 캐릭터 제어, 프롬프트나 LoRA보다 나은 방법이라는 결론은 없다.

온라인 지도(GitHub Pages): https://salixkoreensis94-spec.github.io/gemma4-e2b-neuron-map/

`docs/index.html`을 로컬에서 열어도 한국어 기본·영어 전환 지도를 본다. 데이터·스크립트·스타일은 모두 인라인이며 런타임 요청이 없다. `RESULTS.md`는 수치와 원문 예시, `METHODS.md`는 방법·검증·사전 기준을 설명한다. `data/`는 전 조건 요약과 고정 시나리오 예시를 작은 JSON으로 담는다. 토큰 ID·체크포인트는 없다. S5a는 집계 수만 있고 평가자의 말·개별 표시는 없다.

모델 없이 `python3 code/check_offline.py`로 구문·S6 검증쌍 분류·회귀 예시를 확인한다. `python3 code/build_page.py`로 같은 본문에서 두 HTML을 만든다. 모델을 쓰는 재현 절차와 필요한 수치 입력은 `code/README.md`를 따른다. GGUF·호환 의존성은 사용자가 공급한다. 가중치는 제외했다. 선택한 조향 벡터는 `vectors/`에 포함하며 [벡터 안내](vectors/README.md)와 manifest에 주입 배율·출처를 기록했다. 앱의 등록 벡터는 제외하며 reference register vector의 인용 결과는 저장 출력에서 왔다. 이번 단계에서 모델 의존 재현이나 다른 기기의 실행을 확인하지 않았다.

[읽기] 한 양자화·기본 모델, 짧은 합성 대화, greedy 96토큰에 한정된다. 어미 분류·내용어 겹침은 대리값이며 의미 정답률이 아니다. 공유 틀이 있어 독립 표본이 아니고 다중 탐색의 유의성 검정도 아니다. 긴 문맥과 밀린 전체 생성의 CPU 일치, LoRA 비교는 확인하지 않았다. 방법별 주입 노름도 다르다.
